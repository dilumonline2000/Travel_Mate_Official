# 🌍 Travel Mate - Travel and Tourism Management System

Welcome to **Travel Mate**, a comprehensive Travel and Tourism Management System built to enhance your travel planning experience. Designed with both users and administrators in mind, Travel Mate offers a streamlined way to manage travel operations while optimizing the travel experience for individuals and businesses.

---

## 🚀 About the Project

### Project Name:
Travel Mate

### Project Type:
ITP Project (Year 2, Semester 2)

### Organization:
Travel Mate Officials

### Technologies Used:
- **Frontend**: React.js + Material UI
- **Backend**: Node.js with Express.js
- **Database**: MongoDB

---

## 🌟 Features

### User Features:
- **User Authentication**: Secure login and registration.
- **Travel Destination Management**: Browse and book destinations easily.
- **Train/Bus Ticket Booking**: Select preferred seats and book tickets seamlessly.
- **Hotel Reservations**: Explore and book accommodations.
- **Tour Packages**: Choose from a variety of pre-designed packages.
- **Special Activities**: Book activities like sports or tours.
- **Expense Tracking**: Monitor and manage travel expenses.

### Admin Features:
- **User Management**: Oversee user accounts.
- **Reservation Management**: Handle reservations for destinations, hotels, and activities.
- **Inventory Management**: Manage travel-related services and availability.
- **Analytics Dashboard**: Gain insights into travel trends and user behaviors.

## 🛠️ Installation

### Clone the repository:
```bash
git clone https://github.com/your-username/travel-mate.git
cd travel-mate
```

### Install dependencies:
```bash
# For the backend
yarn install

# For the frontend
cd client
yarn install
```

### Configure environment variables:
Create a `.env` file in the root directory and add the following:
```env
# Backend Environment Variables
MONGO_URI=your_mongo_db_connection_string
JWT_SECRET=your_jwt_secret

# Frontend Environment Variables
REACT_APP_API_BASE_URL=your_backend_api_url
```

### Start the development server:
```bash
# Backend
yarn start

# Frontend
cd client
yarn start
```

## 📋 Usage

### For Users:

### For Administrators:
1. Log in with admin credentials.
2. Manage reservations, user accounts, and services.
3. Analyze trends and optimize offerings via the dashboard.
